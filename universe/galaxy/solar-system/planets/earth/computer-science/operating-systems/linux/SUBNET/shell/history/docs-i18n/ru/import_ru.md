# `shell-history import`

shell-history может импортировать историю из "старого" файла истории

`shell-history import auto` предпринимает попытку определить тип командного интерфейса
(через \$SHELL) и запускает нужный скрипт импорта.

К сожалению, эти файлы содержат не так много информации, как shell-history, так что не 
все функции будут доступны с импортированными данными.

# zsh

```
shell-history import zsh
```

Если у вас есть HISTFILE, то эта команда должна сработать. Иначе, попробуйте

```
HISTFILE=/path/to/history/file shell-history import zsh
```

Этот параметр поддерживает как и упрощённый, так и полный формат.
